# Cloudflare R2 + wrangler

- R2 is S3-compatible object storage. Free tier: 10 GB-month.
- `wrangler r2 object put <bucket>/<key> --file=<path> --remote` uploads one object.
- `wrangler r2 object delete <bucket>/<key> --remote` deletes one object.
- `--pipe` reads the object body from stdin.
- Wrangler v4 targets local simulated storage by default; `--remote` targets the real bucket.
- wrangler caps uploads at 315 MB per object, one object per invocation.
- Auth: `CLOUDFLARE_API_TOKEN` env var; token permission `Workers R2 Storage: Edit`, scopable to specific buckets.
- Bucket `gufime-backup`: `cloudflare_r2_bucket.backup` in `infra/tofu/cloudflare.tf`, location ENAM, Standard class.
- `location` is a placement hint; the API reports actual placement, and config must match it.
- `cloudflare_account_id` loads from `infra/tofu/terraform.tfvars`.
